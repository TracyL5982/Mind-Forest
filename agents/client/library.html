View library

Every way the Renderer can draw one card (components) and every way it can arrange several sibling cards (composites). This page draws them with the same code and styles as the live client, from sample data.

Solid cards are yours. Dashed amber cards are picks the librarian brought and you have not kept.

Under each sample is its type name and its footprint in pixels, which is worked out from the content and never measured.

Any card can carry one line of chips under its content: a date, a place, people and, for what the agents brought, where it came from. A date is never cut to make room for the others. Each type is shown once without chips and once with them. The line adds 28 pixels and nothing else changes.
